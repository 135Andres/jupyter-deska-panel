# Security policy

Notebook Viewer treats every notebook as untrusted. A problem is worth
reporting if a notebook can run script, reach the network, get past the
sanitizer, or read anything other than the notebook open in the panel.

## Supported versions

Only the newest release gets fixes.

## Reporting

Do not open a public issue. Use **Report a vulnerability** on this repository's
[Security tab](https://github.com/135Andres/jupyter-deska-panel/security).
Include the version and a small notebook that shows the problem, with no private
data in it.

A problem in Deska itself belongs with Deska, not here.
